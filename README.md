# Практическая работа 1 — Data Placement Map

Кейс: образовательная платформа **«Курсатор»**.
Задача: распределить 9 сущностей/потоков данных между хранилищами, обосновать выбор,
указать источник истины и описать синхронизацию производных хранилищ.

## Итоговый стек

| Хранилище | Роль |
|---|---|
| **PostgreSQL** | Источник истины для пользователей, прав, метаданных курсов, прогресса, форума, платежей |
| **Redis** | Сессии (источник истины), кэш профилей и прогресса, счётчики, витрина рекомендаций |
| **MongoDB** | Тело курса: модули → уроки → материалы (гибкая схема, вложенность) |
| **ClickHouse** | Логи действий (источник истины событий), аналитические витрины, расчёт рекомендаций |
| **Elasticsearch** *(предложено сверх списка)* | Производный поисковый индекс по курсам |
| **Kafka** *(предложено сверх списка)* | Транспорт событий и CDC между хранилищами |

Elasticsearch и Kafka добавлены аргументированно — задание это допускает.
Обоснование см. в [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md), пункты 5 и 7.
