# Практическая работа 1 — Data Placement Map

Кейс: образовательная платформа **«Курсатор»**.
Задача: распределить 9 сущностей/потоков данных между хранилищами, обосновать выбор,
указать источник истины и описать синхронизацию производных хранилищ.

## Итоговый стек

| Хранилище | Роль |
|---|---|
| **PostgreSQL** | Источник истины: пользователи, права, метаданные курсов, прогресс, форум, refresh-токены |
| **Redis** | Сессии (источник истины), кэш профиля и прогресса, счётчики лайков, витрина рекомендаций |
| **MongoDB** | Тело курса: модули → уроки → материалы (гибкая схема, вложенность) |
| **ClickHouse** | Логи действий (источник истины событий), аналитические витрины, расчёт рекомендаций |
| **Elasticsearch** *(сверх списка)* | Производный поисковый индекс по курсам |
| **Kafka** *(сверх списка)* | Буфер потока событий и транспорт CDC между хранилищами |

Elasticsearch и Kafka добавлены аргументированно — задание допускает расширение списка.
